Bem, com mais de 400 milhões de repositórios para vasculhar no GitHub (😱)Sem falar em inúmeros outros recursos disponíveis na internet, pode ser difícil saber por onde começar! Se você está procurando repositórios úteis para te ajudar na sua jornada de aprendizado, você está com sorte. Neste boletim, destacamos 10 repositórios cheios de conhecimento, ferramentas e inspiração para ajudar você a programar de forma mais inteligente e tornar seu trabalho mais agradável.

Seja aprimorando suas habilidades de programação, mergulhando em aprendizado de máquina ou criando sua própria tecnologia do zero, esses repositórios têm algo especial para impulsionar sua jornada de desenvolvedor. 🔋 Vamos direitinho!

Recursos 📚 de aprendizagem

  • freeCodeCamp

Com uma comunidade online robusta, você pode obter certificações de desenvolvedor gratuitamente. Este repositório, com quase 400.000 estrelas ⭐️, contém toda a base de código e currículo open source deles. Aprenda algo novo ao lado de uma comunidade vibrante de programadores autodidatas!

  • livros-programação-livres

Este faz o que promete: oferece acesso a ebooks gratuitos sobre muitos temas diferentes de programação. E ainda faz isso em vários idiomas. Enquanto a Fundação de Ebooks Gratuitos, um 501(c)3, organização sem fins lucrativos, atualmente administra o repositório, a própria lista é mantida e atualizada colaborativamente por uma comunidade ativa dedicada a ajudar uns aos outros a encontrar o que precisam para se manterem afiados.

Entrevistas e crescimento 🌱 na carreira

  • programação-entrevista-universidade

Então você conseguiu uma entrevista de programação e está um pouco receoso porque já ouviu tudo sobre o leetcode e os exercícios do quadro branco. 😵💫 É aí que entra o repositório de entrevistas de programação da universidade! Tim, o mantenedor do repositório, usou esse guia de estudos de vários meses para conseguir seu primeiro emprego de programador e disponibilizou gratuitamente o currículo que seguiu, em múltiplas línguas. O repositório é uma fonte de conhecimento e também contém uma lista de livros, preparação de perguntas para entrevistas e muito mais.

  • Orientação-Orientação do Sistema

É mais um recurso de preparação para entrevistas, desta vez especificamente para a entrevista de design de sistemas. Esse repositório vai te preparar não só para realmente projetar sistemas em grande escala, mas também para se sair bem na entrevista sem suar. Comece com um guia de estudos, flashcards, perguntas de exemplo (com soluções), e até desafios de programação. nbsp;

  • Roteiro do desenvolvedor

Talvez você não esteja procurando um novo emprego, mas sim queira se aprofundar e continuar crescendo onde está. O repositório de roteiros para desenvolvedores contém guias interativos e até quizzes para ajudar você a avaliar seu progresso ao longo do caminho.

Aprendizado 🧑 🎓 prático

  • Public-APIs

O que você não pode fazer quando tem a API certa na ponta dos dedos? Apresentado pelo pessoal do APILayer e por uma comunidade de amantes de APIs como você, o repositório Public APIs contém uma enorme lista de APIs gratuitas que você pode usar para seus próprios projetos. E para facilitar ainda mais encontrar exatamente o que você procura, eles têm um índice organizado por área temática!

Projetos 🪐 de código aberto

  • awesome-whisper

Psst... Whisper é um sistema de reconhecimento de fala de código aberto movido por IA, desenvolvido pela OpenAI. Esta "lista incrível" curada pela comunidade reúne uma tonelada de recursos relacionados ao Whisper, incluindo apps, artigos e APIs. Então, se você está pronto para começar a trabalhar com reconhecimento de voz, este repositório é um ótimo lugar para começar.

  • reagir

Uma biblioteca JavaScript para construir interfaces de usuário, o React é amplamente utilizado: dois milhões de desenvolvedores de todo o mundo visitam a documentação do React todo mês. No repositório oficial de código aberto, você pode conferir exemplos para ver se o React é adequado para suas necessidades, seguir um guia para começar, caso seja, e interagir com a comunidade para novas ideias e apoio.

  • Fluxo tensorial

Tensorflow é uma plataforma open source de ponta a ponta para aprendizado de máquina. Este repositório fornece o guia oficial de instalação do projeto, além de uma comunidade robusta e muitos recursos adicionais para aprendizado. Essa é a linha de partida para construir e implantar sua própria aplicação de aprendizado de máquina.

Mas espere, tem mais!

Essa lista de 10 repositórios úteis realmente só arranha a superfície do que você pode encontrar em todo o GitHub. Tente procurar a próxima linguagem de programação ou nova ferramenta que você quer aprender e veja o que consegue encontrar.
